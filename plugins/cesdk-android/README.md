# CE.SDK Android Agent Skills

One portable plugin for CE.SDK development with Kotlin and Jetpack Compose on
Android. It contains `docs`, `explain`, and `build` skills.

The plugin bundles curated Android guides, distilled Dokka API digests, and
runnable starter kits.

```bash
# Claude Code
claude plugin install cesdk-android@imgly

# Codex
codex plugin add cesdk-android@imgly
```

## Usage

In Claude Code, type `/`; in Codex, type `$`. Then select the
matching skill from the `cesdk-android` plugin. Both assistants can also
select a skill automatically from a natural-language request.
