```ts
type BarPosition = "top" | "bottom";
```

This type is used to specify the position of a horizontal bar within the user
interface, such as the navigation bar or the inspector bar.

By setting the position to `'top'` or `'bottom'`, you can control whether the bar
sits above or below the canvas.
