Represents a font.

The Font interface defines the structure of a font within the Creative Editor SDK.
It includes properties for the uri, subFamily, weight, and style.

## Properties

| Property | Type |
| ------ | ------ |
|  `uri` | `string` |
|  `subFamily` | `string` |
|  `weight?` | [`FontWeight`](./api/engine/type-aliases/fontweight.md) |
