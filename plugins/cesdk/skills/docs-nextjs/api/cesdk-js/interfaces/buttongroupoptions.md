Represents options for a button group.

The `ButtonGroupOptions` interface provides a set of properties that control the
behavior and appearance of a button group. These options include settings for the
input label, input label position, children, and suffix.

## Properties

| Property | Type |
| ------ | ------ |
|  `inputLabel?` | `string` | `string`\[] |
|  `inputLabelPosition?` | `"left"` | `"top"` |
|  `children?` | () => `void` |
|  `suffix?` | [`Suffix`](./api/cesdk-js/type-aliases/suffix.md) |
