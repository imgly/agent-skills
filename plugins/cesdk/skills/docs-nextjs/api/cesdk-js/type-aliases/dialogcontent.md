```ts
type DialogContent = 
  | string
  | {
  title?: string;
  message: string | string[];
};
```

Represents the content of the dialog.

The DialogContent type defines the structure of the content that can be displayed within a dialog.
It can be a simple string or an object containing a title and a message, providing flexibility in
how information is presented to users.
