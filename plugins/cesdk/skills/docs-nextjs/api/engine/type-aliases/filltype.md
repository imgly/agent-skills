```ts
type FillType = 
  | FillTypeShorthand
  | FillTypeLonghand;
```

The block type IDs for the fill blocks. These are the IDs used to create new fills
using `cesdk.engine.block.createFill(id)`.
Refer to [FillTypeShorthand](./api/engine/type-aliases/filltypeshorthand.md) and [FillTypeLonghand](./api/engine/type-aliases/filltypelonghand.md) for more details.
