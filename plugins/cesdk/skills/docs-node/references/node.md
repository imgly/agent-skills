## What is CE.SDK?

Creative Editor SDK (CE.SDK) is a fully customizable design editor for web, mobile, and server applications. It enables developers to integrate professional photo, video, and design editing capabilities into their products.

**Key capabilities:**
- Photo editing with filters, adjustments, and effects
- Video editing with timeline, transitions, and export
- Design editing with templates, text, and assets
- Headless/server-side processing for automation
