Height settings for the video timeline.

All fields are optional; an omitted field keeps its current value.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
|  `height?` | `number` | `"auto"` | A number fixes the timeline to that height in pixels. `'auto'` restores the default behaviour: the timeline grows and shrinks to hug its content. |
|  `maxHeight?` | `number` | A number caps how tall the timeline may get, in pixels — both when it grows with its content and when it is resized by hand. |
