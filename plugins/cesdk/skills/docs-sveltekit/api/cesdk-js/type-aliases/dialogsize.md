```ts
type DialogSize = "regular" | "large";
```

Represents the size of the dialog.

The DialogSize enum defines the possible sizes for dialogs within the Creative Editor SDK.
Each size corresponds to a different dimension, allowing for flexibility in how dialogs are
displayed to users.
