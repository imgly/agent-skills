# Video

- **Package:** `@imgly/camera-react-native` (React Native, TypeScript)
- **Kind:** interface
- **Import:** `import { Video } from '@imgly/camera-react-native';`

An individual video.

```typescript
interface Video
```

## Members

### uri

- **Kind:** Property

```typescript
uri: string
```

A url to the video file that is stored
in a temporary location.

### rect

- **Kind:** Property

```typescript
rect: Rect
```

A rect that contains the position of
each video as it was shown in the
camera preview (iOS only).
