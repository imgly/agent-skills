# SourceType

- **Package:** `@imgly/editor-react-native` (React Native, TypeScript)
- **Kind:** enum
- **Import:** `import { SourceType } from '@imgly/editor-react-native';`

Defines all available types of source that can be
loaded into the editor.

```typescript
enum SourceType
```

## Values

### SCENE

```typescript
SCENE = 'scene'
```

A scene file (`.imgly` or the legacy `.scene`).

### IMAGE

```typescript
IMAGE = 'image'
```

An image, e.g. `.png`.

### VIDEO

```typescript
VIDEO = 'video'
```

A video, e.g. `.mp4`.
