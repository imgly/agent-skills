# AssetFacetPath

- **Module:** `IMGLYEngine`
- **DocC identifier:** `/documentation/IMGLYEngine/AssetFacetPath`

A property path that can be faceted: `"groups"`, `"tags"`, or `"meta.<key>"`. `"label"` and `"id"` are not facetable because their cardinality is unbounded.

```swift
typealias AssetFacetPath = String
```
