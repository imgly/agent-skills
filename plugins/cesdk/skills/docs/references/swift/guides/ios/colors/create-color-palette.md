On iOS the editor's color palette is set through a single builder method on `EditorConfiguration` — the same surface used for dock, inspector, and theming customization.

See [Color Palette](../user-interface/customization/color-palette.md) for the full guide, including the `NamedColor` shape, the swatch-count rules, and how to wire the palette into your editor configuration.
