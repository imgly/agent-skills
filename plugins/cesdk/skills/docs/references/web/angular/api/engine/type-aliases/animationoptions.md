```ts
type AnimationOptions = object;
```

Options for configuring animations (in, loop, out animations).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
|  `in?` | [`AnimationEntry`](./api/engine/type-aliases/animationentry.md) | Animation when the element enters |
|  `loop?` | [`AnimationEntry`](./api/engine/type-aliases/animationentry.md) | Animation that loops while the element is visible |
|  `out?` | [`AnimationEntry`](./api/engine/type-aliases/animationentry.md) | Animation when the element exits |
