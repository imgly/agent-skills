```ts
type ObjectType = 
  | ObjectTypeShorthand
  | ObjectTypeLonghand;
```

The block type IDs for all blocks types in the Creative Engine. Those are the types that can be
passed to `cesdk.engine.block.findByType(type)` for example.
Refer to [ObjectTypeShorthand](./api/engine/type-aliases/objecttypeshorthand.md) and [ObjectTypeLonghand](./api/engine/type-aliases/objecttypelonghand.md) for more details.
