One bucket of a facet distribution.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
|  `value` | `string` | Raw value exactly as stored on the assets (no casing or locale normalization). |
|  `count?` | `number` | Number of matched assets carrying this value. Always set by local sources; custom sources may omit it when counting is expensive. |
