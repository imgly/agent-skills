```ts
type ScriptStyle = "Normal" | "Superscript" | "Subscript";
```

Represents the script style of a range of text.

- 'Normal': The text sits on the regular baseline at its regular size.
- 'Superscript': The text is scaled down and raised above the baseline.
- 'Subscript': The text is scaled down and lowered below the baseline.
