Represents options for a media preview.

The `MediaPreviewOptions` interface provides a set of properties that control the
behavior and appearance of a media preview. These options include settings for the
size, preview, and action.

## Properties

| Property | Type |
| ------ | ------ |
|  `size?` | `"small"` | `"medium"` |
|  `preview?` | [`PreviewType`](./api/cesdk-js/type-aliases/previewtype.md) |
|  `action?` | [`ButtonOptions`](./api/cesdk-js/interfaces/buttonoptions.md) |
