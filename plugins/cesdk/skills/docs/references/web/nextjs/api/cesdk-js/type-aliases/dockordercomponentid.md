```ts
type DockOrderComponentId = 
  | "ly.img.separator"
  | "ly.img.spacer"
  | "ly.img.assetLibrary.dock"
  | string & object;
```

Represents the ID of a dock order component.

The DockOrderComponentId type defines the possible IDs for components that can be used in the dock order.
It includes predefined IDs for separators and spacers, as well as a catch-all type for custom IDs.
