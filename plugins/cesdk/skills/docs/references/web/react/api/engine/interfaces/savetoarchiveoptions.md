Options for saveSceneToArchive operation.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
|  `compression?` | [`CompressionOptions`](./api/engine/interfaces/compressionoptions.md) | Compression applied to the scene inside the archive. Defaults to Zstd. Bundled media is always stored uncompressed, because it already is in compressed formats. |
