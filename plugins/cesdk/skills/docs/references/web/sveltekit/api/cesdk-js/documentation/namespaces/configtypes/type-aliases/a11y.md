```ts
type A11y = object;
```

Represents the accessibility settings for the Creative Editor SDK.
This type defines the heading hierarchy start level, which can be a number between 1 and 6.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
|  `headingsHierarchyStart` | `1` | `2` | `3` | `4` | `5` | `6` | The option define a level of heading to start from (in a range 1-6) |
